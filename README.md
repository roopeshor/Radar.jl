# Radar.jl

Port of Radar Signal Processing stack ([https://github.com/roopeshor/Radar-Signal-Processing](https://github.com/roopeshor/Radar-Signal-Processing)) in Julia.


## using
install all packages
> `julia --project=. -e 'using Pkg; Pkg.instantiate()'`

run the script
> `julia --project=. test.jl'`
